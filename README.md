# Video RBT - Magic Companion

A modern Video Ring Back Tone (Video RBT) subscription landing page for VybCall, featuring 3D carousel, video previews, and multi-mode subscription flows.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## 📱 Features

- 🎨 **Aurora Gradient UI** - Glass morphism design with smooth animations
- 🎞️ **3D Video Carousel** - Interactive swipeable carousel with autoplay
- 📊 **Analytics Dashboard** - Built-in tracking system with viewer
- 🎯 **Multi-Mode Flow** - SMS OTP / 1-Click Carrier / WiFi subscription
- 🔊 **Video Controls** - Sound toggle, fullscreen, play/pause
- 📱 **Mobile-First** - Fully responsive design
