# Product Requirements Document (PRD)

## 项目概览

### 项目名称
Video RBT - Magic Companion 视频彩铃订购 H5

### 产品定位
广告投放场景下的视频彩铃订购落地页，面向肯尼亚市场，支持多种订购模式。

### 目标用户
- **主要用户**：18-35岁，肯尼亚本地用户
- **设备**：移动端为主（iOS/Android）
- **网络环境**：WiFi / 移动数据网络
- **触达方式**：社交媒体广告（Facebook/Instagram/TikTok）

---

## 业务背景

### 市场需求
- 肯尼亚视频彩铃市场增长迅速
- 用户期望更直观的视频预览体验
- 需要适配不同网络环境的订购流程

### 商业目标
1. 提升订购转化率（目标：> 15%）
2. 降低用户流失率（目标：< 40%）
3. 提高视频观看完成率（目标：> 60%）
4. 收集用户行为数据，优化产品

---

## 用户故事

### Story 1: 视频浏览
**作为** 广告点击进入的用户  
**我想要** 快速浏览多个视频彩铃  
**以便** 找到我喜欢的内容

**验收标准**：
- 首屏展示 3D 轮播视频
- 视频自动播放（默认静音）
- 支持左右滑动切换
- 底部展示推荐网格

### Story 2: 视频试听
**作为** 对某个视频感兴趣的用户  
**我想要** 全屏播放并听到声音  
**以便** 完整体验视频彩铃效果

**验收标准**：
- 点击视频进入全屏播放器
- 支持声音开关
- 支持播放/暂停控制
- 播放进度条显示

### Story 3: 快速订购（移动数据用户）
**作为** 使用移动数据的用户  
**我想要** 一键完成订购  
**以便** 快速激活服务

**验收标准**：
- 自动识别移动数据用户
- 点击订购后直接显示结果
- 无需输入手机号和验证码

### Story 4: 安全订购（WiFi用户）
**作为** 使用 WiFi 的用户  
**我需要** 通过手机号验证  
**以便** 确保账号安全

**验收标准**：
- 输入肯尼亚手机号（9位，+254前缀）
- 发送短信验证码
- 60秒倒计时
- 验证码校验

### Story 5: 结果反馈
**作为** 完成订购的用户  
**我想要** 清楚知道订购结果  
**以便** 了解下一步操作

**验收标准**：
- 成功：显示订购成功，激活彩铃名称
- 失败：显示失败原因（余额不足/网络错误/服务异常）
- 提供重试或返回首页选项

## 功能需求

### 1. 首页

#### 1.1 视频轮播
- **功能描述**：3D 旋转木马效果，展示 3 个视频
- **交互**：
  - 自动播放当前视频（静音）
  - 左右滑动切换
  - 点击非中心视频切换到该视频
- **视觉**：缩放 + 透明度变化

#### 1.2 视频控制
- 声音开关（静音/取消静音）
- 播放/暂停
- 全屏播放

#### 1.3 推荐网格
- 双列布局
- 每个卡片显示：缩略图、标题、价格、订购按钮
- 点击卡片打开大屏播放器

#### 1.4 订购入口
- Hero 区域：主要 CTA 按钮
- 推荐卡片：每个卡片带订购按钮

### 2. 手机号验证页

#### 2.1 手机号输入
- **格式**：+254 前缀 + 9 位本地号码
- **校验**：
  - 非空校验
  - 纯数字校验
  - 长度校验（9位）
- **错误提示**：实时显示错误信息

#### 2.2 验证码
- **获取验证码**：
  - 60秒倒计时
  - 倒计时期间禁用按钮
  - 支持重新发送
- **输入**：纯数字，最多 6 位
- **校验**：
  - 验证码正确性
  - 过期检查

#### 2.3 模式适配
- **移动数据用户**：隐藏验证码区域，显示"1-Click"标识
- **WiFi用户**：显示完整验证流程

### 3. 订购结果页

#### 3.1 成功状态
- 显示：🎉 表情 + "Subscription Successful"
- 展示订购的彩铃名称
- 操作：Enjoy Now（返回首页）

#### 3.2 失败状态
- **余额不足**：💳 + "Payment Failed"
- **激活失败**：⚠️ + "Activation Failed"
- **网络错误**：📡 + "Network Error"
- **服务不可用**：🛠️ + "Service Unavailable"
- 操作：Try Again（重试）

#### 3.3 重试机制
- 移动数据用户：直接重试订购
- WiFi用户：返回验证页
- 连续失败 ≥2 次：显示"Back to Home"按钮

### 4. Demo 控制器

#### 4.1 网络模式切换
- Mode A：WiFi / 新访客（需验证码）
- Mode B：移动数据用户（1-Click）
- Mode C：WiFi / 老用户（需验证码）

#### 4.2 结果模拟
- Success：订购成功
- Payment Failed：余额不足
- Activation Failed：激活失败
- Wrong Code：验证码错误
- Expired Code：验证码过期
- Network Error：网络错误
- Service Unavailable：服务不可用

## 非功能需求

### 性能
- **首屏加载**：< 3s (3G网络)
- **视频自动播放**：< 500ms 延迟
- **页面切换动画**：60fps 流畅
- **包体积**：< 500KB (gzip)

### 兼容性
- **浏览器**：Chrome 90+, Safari 14+, Android WebView
- **设备**：iOS 14+, Android 8+
- **屏幕**：支持 320px - 430px 宽度

### 安全
- 防止短信轰炸（同一号码 1 分钟内只能发 1 次）
- 验证码 5 分钟过期
- 敏感信息不存储在前端

### 可用性
- 所有交互元素可点击区域 ≥ 44x44px
- 错误提示清晰易懂
- 支持键盘输入（数字键盘）

## UI/UX 设计要求

### 视觉风格
- **主题**：Aurora 渐变（紫色→橙色）
- **效果**：玻璃态（Glass Morphism）
- **动画**：柔和过渡，呼吸效果

### 颜色规范
- **主色**：#FFD05B（金色）
- **背景渐变**：#1A0B2E → #FF6B35
- **玻璃态**：rgba(255, 255, 255, 0.08)
- **边框**：rgba(255, 255, 255, 0.18)

### 字体规范
- **标题**：700 粗体
- **正文**：400 常规
- **按钮**：600 半粗

### 响应式
- **移动优先**：主要适配 375px 宽度
- **最大宽度**：430px
- **居中显示**：超出最大宽度时居中

## 风险与限制

### 技术风险
- **视频加载慢**：预加载 + CDN 加速
- **自动播放被阻止**：降级为点击播放
- **内存占用高**：限制视频数量，及时释放

### 业务风险
- **短信成本**：限制发送频率
- **欺诈订购**：验证码 + 运营商验证
- **转化率低**：A/B 测试优化

### 已知限制
- 仅支持肯尼亚市场（+254）
- Demo 阶段无真实支付
- 无后端接口（纯前端模拟）
